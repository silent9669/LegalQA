## Purpose
The legacy documents in this repository covering V7 through V15 fixes (e.g. `LEGALQA_V14_KAGGLE_FULL_QLORA_OOM_FIX.md`, `LEGALQA_V15_T4_QLORA_CE_CHUNK_GENERATOR_PROBE_FIX.md`, earlier superpowers plans/specs) represent chronological research logs and experimental evidence.

They serve as valuable historical context explaining why specific configurations (such as TRL `chunked_nll` chunk-size reduction from 256 to 32 failing with 594 MiB OOM on LM-head projection) were retired. They MUST NOT be used to override the active V16 specification.
