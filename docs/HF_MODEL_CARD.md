# LegalQA Task 2 — Qwen2.5-3B-Instruct Vietnamese Legal QA Platform

This repository hosts official audited models, adapters, retrieval encoders, and reproducible run bundles for **Task 2 (Vietnamese Legal QA)** of the **UIT Data Science Challenge (DSC) 2026**.

## 1. System Architecture

The pipeline implements an audited, leakage-safe retrieval-augmented generation (RAG) architecture:
1. **Exact & Deep Memory Layer**: Catches verbatim and normalized question matches against official reference pairs.
2. **Hybrid Multi-Arm Retrieval**:
   - **Sparse Channel**: BM25S with Vietnamese word segmentation.
   - **Dense Channel**: `encoder_ft_v2` (Matryoshka-tuned DEk21 on Vietnamese legal question-chunk pairs, dimensions: [768, 512, 256]).
   - **Legal Reference Channel**: Exact doc-number and article parsing (e.g. *Điều 17 Nghị định 90/2017/NĐ-CP*).
   - **Fusion**: Weighted Reciprocal Rank Fusion (RRF, k=60).
3. **Neural Cross-Encoder Reranking**: `BAAI/bge-reranker-v2-m3` running on GPU Tensor Cores.
4. **Generator**: `Qwen/Qwen2.5-3B-Instruct` fine-tuned with 4-bit NF4 QLoRA, selective Liger fused-linear cross-entropy, and non-reentrant gradient checkpointing.
5. **Dual-Part Answer Assembly**:
   - **Part 1 (Reasoning & Conclusion)**: Concise, fact-grounded statutory answer generated by the fine-tuned LLM.
   - **Part 2 (Statutory Citation Block)**: Full verbatim legal article text (`Trích dẫn quy định:\n...`).
   - **Length Calibration**: Targets the gold reference distribution (mean ~850 words).

## 4. Usage & Checkpoint Loading

### Load Fine-Tuned QLoRA Generator Adapter:
```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel

base_id = "Qwen/Qwen2.5-3B-Instruct"
repo_id = "dangphuc2109/legalqa-qwen2.5-3b-adapter"
subfolder = "runs/run_d2618710d9d0b6de_20260921_154231/final_adapter"

tokenizer = AutoTokenizer.from_pretrained(repo_id, subfolder=subfolder)
model = AutoModelForCausalLM.from_pretrained(
    base_id,
    torch_dtype=torch.bfloat16,
    device_map="cuda:0",
)
model = PeftModel.from_pretrained(model, repo_id, subfolder=subfolder)
```

### Load Fine-Tuned Dense Retriever (`encoder_ft_v2`):
```python
from sentence_transformers import SentenceTransformer
from huggingface_hub import snapshot_download

folder = snapshot_download(
    repo_id="dangphuc2109/legalqa-qwen2.5-3b-adapter",
    allow_patterns="runs/20260920-215402/encoder_ft_v2/*",
)
dense_model = SentenceTransformer(f"{folder}/runs/20260920-215402/encoder_ft_v2")
```
